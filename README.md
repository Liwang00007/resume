# 李旺仔个人简历主页

这是部署到 GitHub Pages 的个人简历主页，仓库地址：

https://github.com/Liwang00007/resume

如果 GitHub Pages 已开启，网页地址通常是：

https://liwang00007.github.io/resume/

## 怎么更新网页

1. 修改 `index.html` 或 `photo.jpg`
2. 提交到 GitHub
3. 等 GitHub Pages 自动刷新

常用命令：

```powershell
git status
git add index.html photo.jpg .gitignore README.md
git commit -m "优化个人简历主页"
git push origin main
```

## 怎么查看 GitHub Pages 是否开启

打开仓库页面，进入：

`Settings` -> `Pages`

如果看到 `Your site is live at ...`，那一行就是网页链接。
